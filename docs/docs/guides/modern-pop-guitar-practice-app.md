## 2) 단계별 연습 방법 (전체 플렛 커버)

### 단계 1: 지도 만들기 (1~2주)
**목표:** 프렛보드 전체에서 루트/스케일 위치를 확실히 기억.
- 메이저/마이너 스케일 5포지션을 **하루 1키씩** 순환.
- **루트(1도)만 표시**하면서 한 줄(1현)씩 이동.
- 하루 2키 이상 금지 → “정확히 보는 습관” 우선.

### 단계 2: 포지션 연결 (2~4주)
**목표:** 포지션 간 이동을 자연스럽게 연결.
- 1포지션 → 2포지션 연결 패턴 연습.
- **슬라이드/포지션 점프**를 포함한 짧은 프레이즈 만들기.
- 메트로놈 60~90BPM에서 정확성 위주.

### 단계 3: 리듬 우선 (2~3주)
**목표:** 모던 팝 특유의 타이트한 리듬 구현.
- 8비트/16비트 스트로크 패턴.
- **뮤트/고스트 노트** 삽입.
- 드럼 루프 위에서 **리듬만 연주**.

### 단계 4: 톤 + 표현력 (2~3주)
**목표:** 크런치/드라이브 톤으로 클린/드라이브 간 표현.
- 크런치 톤에서 다이내믹 피킹 연습.
- 벤딩, 비브라토, 하이브리드 피킹 강화.
- **모던 팝 리프**를 톤 맞춰 재현.

### 단계 5: 실전형 루틴 (상시)
**목표:** “완주형 곡 연습”으로 실전 대응.
- 곡을 **인트로/버스/후렴/브릿지**로 분해.
- 각 파트를 **1분짜리 루프**로 반복 연습.
- **녹음 후 피드백** 필수.

1. 워밍업 5분

4. 톤 세팅/표현 10분

> 주 2회는 반드시 **실전 곡 완주** 연습을 포함.

## 4) “크런치/드라이브” 앱 기획 가이드

### A. 문제 정의
- **대부분의 기타 연습은 “일정한 루틴”이 없고**, 기록이 어렵다.
- 실전 곡에서 필요한 **리듬/포지션/톤 통합 훈련**이 부족하다.

### B. 핵심 가치 제안
- “모던 팝 전용” 실전 루틴 제공
- **전체 플랫 커버** + **곡 기반 미션**
- 연습 기록 → 성장 시각화

### C. 핵심 기능
1. **연습 플로우 생성기**
   - 목표 입력(레벨/키/스타일) → 자동 루틴 생성
2. **프렛보드 전체 지도 모드**
   - 루트 표시 + 포지션 이동 시각화
3. **리듬 트레이너**
   - 16비트/싱코페이션/뮤트 연습
4. **톤 프리셋**
   - 크런치/드라이브 톤 시뮬레이션
5. **실전 미션 모드**
   - 곡 파트별 루프 + 난이도 점수
6. **연습 노트 자동 기록**
   - BPM/시간/정확도 자동 저장

## 5) 실행 로드맵 (MVP → 확장)

### 1단계: MVP (4~8주)
- 연습 노트 기록 기능
- 프렛보드 포지션 시각화
- 기본 루틴 템플릿 제공

### 2단계: 리듬/톤 기능 (8~12주)
- 리듬 패턴 메트로놈 + 루프
- 크런치/드라이브 톤 프리셋

### 3단계: 실전형 미션 (12~20주)
- 곡 단위 연습 모드
- 점수화/레벨업 시스템

### 4단계: 커뮤니티/콘텐츠 확장
- 유저가 만든 루틴 공유
- 모던 팝 리프/곡 데이터베이스

## 7) 제안하는 개발 구조 (간단)

- **프론트:** React Native (모바일 중심)
- **백엔드:** Node.js + PostgreSQL
- **오디오:** Web Audio API 또는 JUCE
- **데이터:** 연습 로그 + 루틴 템플릿 + 곡 미션

## 마무리

이 앱은 단순 연습 기록이 아니라 **“실전형 기타 루틴 시스템”**을 제공합니다. 
핵심은 **전체 플랫 커버 + 리듬 + 톤 + 실전 미션**의 결합입니다.

원한다면 다음 단계로 **UI 와이어프레임**, **레벨별 콘텐츠 설계**, **구체적 모던 팝 리프 리스트**까지 확장해드릴 수 있습니다.
